# Student Registration App

A vanilla JavaScript student registration application built as part of my web development learning journey.

## Features

- Register students
- Form validation
- Duplicate email prevention
- Edit student data
- Delete students
- Search by student name
- Sort by name and course
- Pagination
- Adaptive page navigation
- Items per page selector
- LocalStorage persistence

## Built With

- HTML
- CSS
- JavaScript
- Browser LocalStorage API

## What I Learned

Through this project I practiced:

- DOM manipulation
- Event handling
- Array methods
- Form validation
- Application state
- LocalStorage
- JSON
- Search and sorting
- Pagination logic
- Function decomposition
